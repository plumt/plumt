# 안녕하세요, 모바일 앱 개발자 이윤성입니다

Android를 주력으로 앱을 만듭니다. 클린 아키텍처로 앱을 모듈 단위로 조립하고,
CI/CD와 테스트 같은 반복 업무는 AI가 처리하도록 자동화하는 데 관심이 많습니다.

- AOS·iOS 앱을 개발·운영하며 Kotlin Multiplatform으로 고도화하고 있습니다.
- 개인 앱 6개(Lottomate, Lunar, QRScanner, Diding, Moduta, Fxrate)를 하나의 모노레포로 관리합니다.
- CI/CD, 홈서버, 메신저, 로컬 LLM, AI 하네스를 구성하고 운영합니다.
